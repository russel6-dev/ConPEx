# Kebijakan Privasi ConPEx

ConPEx **tidak mengumpulkan, menyimpan, atau mengirim** data apa pun.

- Semua pemrosesan dilakukan di komputer Anda, termasuk pembacaan PDF, OCR, pengecekan angka, dan pembuatan Excel.
- File PDF, isi transaksi, dan password PDF tidak pernah dikirim ke server mana pun, termasuk server pembuat extension.
- Tidak ada analitik, pelacakan, iklan, atau akun.
- Satu-satunya data yang disimpan adalah pilihan terakhir Anda di menu (jenis dokumen, bank, cara baca), di penyimpanan lokal browser.
- Izin akses situs hanya diminta bila Anda memilih mengambil PDF dari tab yang sedang terbuka, dan hanya untuk situs tersebut.

Pertanyaan: buka *Issue* di repository GitHub ConPEx.
