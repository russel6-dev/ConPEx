File app.html dibuka langsung (klik dua kali), jadi Chrome memblokir mesin OCR dan sebagian fitur. ConPEx harus dipasang sebagai extension lalu dibuka dari ikonnya:

  1. Buka alamat chrome://extensions di Chrome (Edge: edge://extensions).

PDF dari tab:

File

    Cara pakai

    1. Seret PDF rekening koran atau buku besar ke kotak di atas.
    2. Lihat hasil pengecekan. Baris merah saldonya tidak cocok, sel kuning perlu dicek manual.
    3. Klik sel tabel untuk memperbaiki angka. Pengecekan langsung dihitung ulang.
    4. Klik Unduh Excel. Excel berisi rumus cek dan sheet Rekonsiliasi.

    Yang dicek otomatis

    • Saldo per baris: saldo sebelumnya + kredit − debit = saldo tercetak.
    • Total debit, total kredit & jumlah transaksi vs ringkasan bank.
    • Saldo akhir, kesinambungan antar halaman & antar file (bulan).
    • Buku besar: saldo per akun, baris Total per akun, debit = kredit.

    Analisis uang masuk (opsional)

    • Nyalakan di pilihan Analisis uang masuk. Setiap uang masuk ditandai: indikasi penghasilan usaha, bunga, bukan penghasilan, atau perlu dicek.
    • Kata lengkap, singkatan, dan typo dikenali. Ganti kategori lewat dropdown, lalu jadikan aturan agar berlaku untuk file berikutnya.
    • Excel mendapat sheet rekap bulanan (ekualisasi), rincian (pemeriksaan), dan ringkasan.

    Tips

    • PDF berpassword (e-statement): masukkan password saat diminta.
    • Scan sebaiknya lurus & jelas (minimal 200 dpi).
    • Bank: BCA, Mandiri, BRI, BNI, BSI, CIMB, Permata, Danamon, BTN, dll. Format lain dibaca dengan mode umum.
